# TrigPlay: Math That Makes Games Move

An interactive web app that shows how trigonometry is used in video game development. Built as a Basic Mathematics microproject.

🔗 **Live demo:** https://trigplay-math-that-make-games-move.vercel.app/

## Features
- Movement simulator showing how sine and cosine move characters
- Game-style examples inspired by Minecraft and Fortnite
- Integral calculus and coordinate geometry sections (hitboxes and aiming)
- Dark neon gaming theme with scroll-reveal animations

## Built With
- HTML
- CSS
- Vanilla JavaScript

## Run It Locally
1. Download `index.html`
2. Double-click it to open in your browser
